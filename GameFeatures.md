# 🎮 Programming Concepts Covered in the Project

| #  | Concept                              | Programming Problem Covered                                                                 |
|----|--------------------------------------|---------------------------------------------------------------------------------------------|
| 1  | 🎲 Generating Random Numbers        | Generate a random number within a range (`RandomNumber()`).                                 |
| 2  | ⌨️ Handling User Input              | Read and validate user input (Rock-Paper-Scissors choices).                                 |
| 3  | 🔀 Conditional Logic                | Implement decision-making using `if` and `switch-case`.                                     |
| 4  | ✏️ String Manipulation              | Convert enum values into readable strings (`ChoiceName()`, `WinnerName()`).                 |
| 5  | 🔄 Looping (For & While Loops)      | Iterate through multiple rounds using loops.                                                |
| 6  | 📦 Creating Functions               | Write reusable functions to handle various tasks (`ReadPlayer1Choice()`, `PlayGame()`).     |
| 7  | 🤖 Generating Computer Choices      | Simulate AI behavior by randomly selecting a move.                                          |
| 8  | ⚖️ Comparing Values                 | Determine winners based on user vs. computer choices.                                       |
| 9  | ♻️ Game Loop & Replay Feature       | Allow the user to play multiple rounds with replay functionality.                           |
| 10 | 🧹 Clearing the Screen (System Calls) | Use `system("cls")` to refresh the screen between games.                                  |
| 11 | 📊 Tracking Scores                  | Store and update player wins, computer wins, and draws.                                     |
| 12 | 🚩 Working with Boolean Logic       | Compare values to determine if the game should continue.                                    |
| 13 | 🔁 Reading and Returning Values from Functions | Use return values for `whoWonTheRound()`, `whoWonTheGame()`.                     |
| 14 | 🔀 Switch-Case for Decision Making  | Implement a structured approach to evaluating game logic.                                   |
| 15 | 🌱 Using `srand(time(NULL))` for Unique Random Numbers | Ensure different results in each game.                                   |
| 16 | 🛡️ Handling Edge Cases              | Validate user input to prevent invalid choices.                                             |
| 17 | 🧠 Implementing a Simple AI (Computer Player) | Generate non-human opponent decisions.                                            |
